## 3. Initial Setup

### Step 1: Create Account

1. Go to https://www.squarespace.com
2. Click "Get Started"
3. Create account with email
4. Choose "Business" or "Nonprofit" as website type
5. Enter "Women's Center of Wake County" as site name

### Step 2: Choose Template

1. Browse templates
2. Select **Romer** (recommended)
3. Click "Start with this design"

### Step 3: Initial Configuration

**Site Title Settings:**
1. Click **Settings** → **Business Information**
2. Enter:
   - Business Name: Women's Center of Wake County
   - Tag Line: safety • stabilization • transformation
   - Address: 2200 New Bern Ave. Raleigh, NC 27610
   - Phone: 919-829-3711
   - Email: info@wcwc.org

**Domain Setup:**
1. Go to **Settings** → **Domains**
2. Option A: Connect existing domain (wcwc.org)
3. Option B: Purchase new domain
4. Follow Squarespace instructions to update DNS

### Step 4: Enable Required Features

**Forms:**
1. **Settings** → **Forms**
2. Enable **Form Storage**
3. Set email notifications to info@wcwc.org

**Donations:**
1. **Settings** → **Payments**
2. Connect Stripe or Square account
3. Enable donation button

**Analytics:**
1. **Settings** → **Analytics**
2. Connect Google Analytics (recommended)
3. Enable Squarespace Analytics

## 4. Brand & Design Settings

### Color Palette Setup

1. Click **Design** → **Colors**
2. Set color theme:

**Color Palette Configuration:**

```
Theme: Custom

Primary Colors:
- Color 1 (Cyan): #00BCD4
- Color 2 (Pink): #E91E63  
- Color 3 (Green): #8BC34A

Neutral Colors:
- Background: #FFFFFF (white)
- Text: #374151 (dark gray)
- Accent Gray: #F3F4F6 (light gray)

Button Colors:
- Primary Button: #E91E63 (pink)
- Secondary Button: #00BCD4 (cyan)
- Tertiary Button: #8BC34A (green)
```

**How to Set:**
1. **Design** → **Colors** → **Edit**
2. For each color, click the color swatch
3. Enter hex code (e.g., #00BCD4)
4. Click "Save"

---

### Typography Settings

1. Click **Design** → **Fonts**

**Recommended Font Pairings:**

**Option 1 - Clean & Modern:**
- Headings: **Poppins** (Bold, 600)
- Body: **Inter** (Regular, 400)
- Buttons: **Poppins** (SemiBold, 600)

**Option 2 - Professional:**
- Headings: **Montserrat** (Bold, 700)
- Body: **Open Sans** (Regular, 400)
- Buttons: **Montserrat** (SemiBold, 600)

**Option 3 - Friendly:**
- Headings: **Outfit** (Bold, 700)
- Body: **Source Sans Pro** (Regular, 400)
- Buttons: **Outfit** (SemiBold, 600)

**Font Size Adjustments:**
1. **Design** → **Font Size**
2. Set scale:
   - Heading 1: 48px - 60px (desktop)
   - Heading 2: 36px - 48px
   - Heading 3: 24px - 30px
   - Body: 16px - 18px
   - Small: 14px

---

### Site Styles

1. Click **Design** → **Site Styles**

**Button Styles:**
- Shape: **Rounded** (24px radius)
- Size: **Large**
- Padding: **Medium to Large**
- Hover effect: **Lift** or **Darken**

**Card Styles:**
- Shadow: **Medium**
- Border Radius: **12px**
- Spacing: **Medium**

**Section Spacing:**
- Padding: **Large** (80px - 120px)
- Between elements: **Medium** (40px - 60px)

**Animation:**
- Enable **Scroll Effects** for fade-ins
- Keep animations **Subtle**
- Duration: **Fast** (300ms)

---

### Logo Setup

**Option 1: Text Logo (Recommended)**
1. **Design** → **Logo & Title**
2. Enable **Text Logo**
3. Enter: "The Women's Center"
4. Set font to heading font
5. Add tagline: "safety • stabilization • transformation"

**Custom CSS for Multi-Color Logo:**
```css
/* Navigate to Design → Custom CSS */

/* Multi-colored logo */
.header-title-logo a {
  font-size: 28px !important;
  font-weight: 700 !important;
  line-height: 1.2 !important;
}

/* Color spans - will need to edit in Code Block */
.logo-cyan { color: #00BCD4; }
.logo-pink { color: #E91E63; }
.logo-green { color: #8BC34A; }
```

**Option 2: Image Logo**
1. Design logo in Canva or hire designer
2. Upload as PNG (transparent background)
3. Recommended size: 300px × 100px
4. Upload at **Design** → **Logo & Title**

## 6. Forms & Integrations

### Form Configuration

**For ALL Forms on Site:**

1. **Form Settings:**
   - Go to each form → **Edit** → **Storage & Email**
   - Email notifications to: info@wcwc.org
   - Enable **Store Submissions** (view in dashboard)
   - Enable **CAPTCHA** (prevent spam)

2. **Form Styling:**
   - **Design** → **Form Styles**
   - Field style: Rounded
   - Button style: Primary (pink)
   - Field spacing: Medium
   - Label position: Top

3. **Confirmation:**
   - Show message: "Thank you! We'll be in touch soon."
   - OR redirect to thank-you page

---

### Donation Integration

**Stripe Setup (Recommended):**

1. **Settings** → **Payments** → **Connect Stripe**
2. Create Stripe account (or connect existing)
3. Complete verification
4. Enable **Donations**
5. Set suggested amounts: $25, $50, $100, $250
6. Enable recurring donations

## 10. Limitations & Workarounds

### Squarespace Limitations

#### **Limitation 1: Multi-Color Logo (Text)**

**Issue:** Can't easily make "The" cyan, "Women's" pink, "Center" green in text logo.

**Workarounds:**
1. **Use Image Logo:** Design in Canva with colors, upload
2. **Custom CSS:** Add code injection (requires Business plan)
3. **Accept Single Color:** Use one brand color for simplicity

---

#### **Limitation 2: Advanced Animations**

**Issue:** Limited hover effects compared to custom code.

**Workarounds:**
1. Use built-in **Scroll Effects** (fade, slide)
2. Add subtle **Button Hover Effects** (lift, darken)
3. Accept simpler animations for ease of maintenance

---

#### **Limitation 3: Custom Form Logic**

**Issue:** Can't create multi-step forms or conditional fields easily.

**Workarounds:**
1. Use **Typeform** or **JotForm** (embed)
2. Break into multiple simple forms
3. Use **Dropdown** to simulate conditional logic

---

#### **Limitation 4: Statistics Counter Animation**

**Issue:** Numbers don't "count up" on scroll.

**Workarounds:**
1. Display static numbers (still effective)
2. Use **GIF** of counting animation
3. Embed **Odometer.js** via Code Injection (advanced)

---

#### **Limitation 5: Footer Wavy Border**

**Issue:** Can't easily add custom SVG border.

**Workarounds:**
1. Upload wavy border as **background image** (PNG with transparency)
2. Use **CSS** to add via Code Injection
3. Accept straight border (clean, still professional)

**CSS Code:**
```css
footer {
  border-top: 4px solid #374151;
  position: relative;
}
```

---

#### **Limitation 6: Gradient Text**

**Issue:** Can't apply gradient to text natively.

**Workarounds:**
1. Use solid brand colors (cyan, pink, green)
2. Add **Custom CSS**:
```css
.gradient-text {
  background: linear-gradient(90deg, #00BCD4, #E91E63);
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
}
```
3. Create text as **image** (not ideal for SEO)

---

#### **Limitation 7: Button Gradients**

**Issue:** Buttons only support solid colors.

**Workarounds:**
1. Use solid pink (#E91E63) - still looks professional
2. Add subtle shadow for depth
3. Custom CSS for gradients (advanced):
```css
.sqs-block-button-element {
  background: linear-gradient(135deg, #E91E63, #D81B60) !important;
}
```

---

#### **Limitation 8: Advanced Grid Layouts**

**Issue:** Limited control over responsive breakpoints.

**Workarounds:**
1. Use built-in responsive settings (usually sufficient)
2. Test on mobile and adjust manually
3. Accept Squarespace defaults (optimized for most screens)

---

### When to Use Custom Development Instead

**Consider custom React site if you need:**
- Complex interactive features (calculators, configurators)
- Custom donation workflows
- Advanced animations throughout
- Integration with multiple custom APIs
- Client portal with login

**Squarespace is great for:**
- Standard nonprofit websites ✅

- Quick launch timelines ✅
